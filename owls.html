OVERVIEW

THE
SYSTEM

A desktop optical system designed to turn live meteorological data into an atmospheric physical interface.

O.W.L.S. — Optical Weather Live-Visualization System — combines a concealed digital display, semi-reflective optical surface, embedded computing, and procedural graphics.

Rather than presenting weather as a conventional dashboard, the system is intended to make atmospheric conditions appear to occupy physical space inside the object.

01
DESIGN INTENT

MAKE DATA
PHYSICAL

What if checking the weather did not feel like checking another screen?

The project began as an exploration of physical computing and unconventional display systems. Instead of designing another weather application, the objective is to build an object whose visual state changes with the atmosphere outside.

Clouds, rain, wind, and environmental lighting become behaviors rather than icons.

01 CONCEAL THE DISPLAY

The screen should function as infrastructure, not the visual focus of the object.

02 VISUALIZE BEHAVIOR

Weather data controls movement, density, particles, and light.

03 PHYSICAL PRESENCE

The final system should read as an object rather than a conventional monitor.

02
OPTICAL PRINCIPLE

REDIRECT
THE IMAGE

O.W.L.S. uses a teleprompter-style Pepper's Ghost configuration.

A concealed LCD faces upward toward a semi-reflective beamsplitter. The reflected image is viewed against a dark internal background, allowing bright rendered objects to appear visually separated from the physical display that produces them.
